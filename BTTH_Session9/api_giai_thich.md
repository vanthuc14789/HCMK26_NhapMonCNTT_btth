<h1 id="giải-thích-thuật-ngữ-api">Giải thích thuật ngữ API</h1>
<h2 id="prompt-gửi-cho-ai">1. Prompt gửi cho AI</h2>
<h3 id="tôi-là-ai--bối-cảnh">Tôi là ai / Bối cảnh</h3>
<p>Em là sinh viên năm nhất ngành Công nghệ thông tin, đang tham gia CLB Lập trình và làm dự án SmartCampus. Em chưa hiểu rõ thuật ngữ API trong lập trình.</p>
<h3 id="chủ-đề--nội-dung-cần-xử-lý">Chủ đề / Nội dung cần xử lý</h3>
<p>Giải thích thuật ngữ API và vai trò của API trong ứng dụng SmartCampus.</p>
<h3 id="yêu-cầu">Yêu cầu</h3>
<ul>
<li>Giải thích API là gì bằng ngôn ngữ đơn giản.</li>
<li>Đưa ra một ví dụ thực tế dễ hiểu.</li>
<li>Giải thích API được sử dụng như thế nào trong SmartCampus.</li>
<li>Trình bày ngắn gọn, phù hợp với sinh viên năm nhất.</li>
</ul>
<h3 id="không-cần">Không cần</h3>
<p>Không cần giải thích các kiến thức lập trình nâng cao hoặc đưa ra đoạn code phức tạp.</p>
<h2 id="câu-trả-lời-của-ai">2. Câu trả lời của AI</h2>
<p>API là giao diện cho phép các phần mềm giao tiếp và trao đổi dữ liệu với nhau. Có thể hiểu API giống như người phục vụ trong nhà hàng: ứng dụng gửi yêu cầu, API chuyển yêu cầu đến hệ thống xử lý rồi trả kết quả về. Trong dự án SmartCampus, API có thể được dùng để lấy dữ liệu lịch học từ máy chủ và hiển thị lên điện thoại của sinh viên.</p>
<h2 id="tóm-tắt-bằng-lời-của-em">3. Tóm tắt bằng lời của em</h2>
<p>API giúp các phần mềm trao đổi dữ liệu với nhau. Trong SmartCampus, API có thể giúp ứng dụng lấy lịch học từ máy chủ để sinh viên xem trên điện thoại. Nhờ đó, ứng dụng có thể nhận dữ liệu mà không cần tự lưu toàn bộ thông tin lịch học.</p>
